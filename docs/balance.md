# v0.3.0 진행량 모델

각 게임을 하루 10~15분씩 즐기며 주요 목표를 약 60일에 달성하는 것이 목표입니다. 사용자는 일일 제한 없이 플레이량으로 조정하는 방향을 선택했습니다. 아래는 실제 reducer와 고정 회로 생성기를 사용하는 계산이며, 사람의 장기 플레이를 측정한 결과가 아닙니다.

`npm run balance`로 재현합니다. 기준은 신규 시작이며, 기존 이용자는 보존한 진행도에서 이어갑니다.

| 하루 게임별 시간 | 광산 | 정원 | 회로 |
|---|---:|---:|---:|
| 10분 | 74.04일 | 67일 | 72.02일 |
| 12.5분 | 59.23일 | 58일 | 57.61일 |
| 15분 | 49.36일 | 49일 | 48.01일 |

## 광산

목표는 1,000층 전체 채굴·광물 30종·곡괭이 10단계입니다. 기존 층의 내구도와 광물 배치를 보존하고 강화 조건을 현재 단계×40층, 비용을 단계²×500코인으로 낮췄습니다.

모델은 타격 1초, 매층 판매와 다음 층 이동 각 2초, 가능한 강화 3초를 사용합니다. 타격 40,400회·판매 1,000회·이동 999회·강화 9회로 총740.42분입니다. 강화 층은40/80/120/160/200/240/306/378/454입니다. 실제 클릭 간격이나 강화·판매 선택에 따라 달라집니다.

## 정원

목표는 40종 직접 수확·화분 12개입니다. 기본 성장 시간은 첫 품종부터60/90/120초, 이후180초이며 물주기는 전체 시간의25%를 줄입니다. 다음 씨앗을 열기 위한 직전 품종 수확량은 다음과 같습니다. 표의 번호는 첫 씨앗을1번으로 셉니다.

| 열 씨앗 번호 | 직전 품종 수확 |
|---|---:|
| 2 | 5회 |
| 3 | 12회 |
| 4 | 20회 |
| 5~9 | 50회 |
| 10~21 | 90회 |
| 22~40 | 120회 |

한 번의 일일 방문에서 성공 행동마다1초를 소비하고, 예산이 남을 때만 다음 행동을 시작합니다. 수확·가능한 확장·최신 해금 씨앗 심기·물주기를 반복하며 불가능하면 성장 시간을 기다립니다. 오프라인 성장도 계산하고, 씨앗 선택과 화면 판독의 별도 시간은 가정하지 않습니다.

12.5분 모델에서58일, 전체 입력201.27분·성장 대기521.08분, 하루 평균 실제 입력3.47분입니다. 10~15분 전체가 계속 클릭하는 시간은 아닙니다. 기다리는 동안 다른 작업을 하거나 중간에 멈출 수 있습니다. 화분12개는 모델에서7~9일에 달성됩니다. 해금 수는 저장하므로 이전판의 열린 씨앗이 다시 잠기지 않습니다.

## 회로

목표300개와 생성기 버전1을 유지해 이미 저장한 회전 상태를 바꾸지 않습니다. 모든 퍼즐을 생성기의 한 정답 방향으로 돌리는 경로는7,328회전입니다. 이는 수학적 최단해나 사람의 실제 회전 횟수가 아닙니다.

모델은 회전0.8초·다음2초, 4×4의 판독/생각90초·5×5의 판독/생각155초를 가정합니다. 입력107.67분과 가정한 사고612.5분을 합쳐720.17분입니다. 작은 회로 하루6~7개, 큰 회로4개가 대략10~15분 안내이며 강제 제한은 없습니다. 숙련도에 따라 일수 편차가 큽니다.

## 보존과 검증

schema4는 정원의 영구 해금 수만 추가합니다. v1/v2/v3 이전은 원본 스냅샷부터 보존하며, 기존 게임 기록·심은 시각·코인·회전·설정·저장 번호를 유지합니다. 새 성장 시간은 이미 심은 식물에도 적용하므로 기존 긴 성장 식물은 더 일찍 수확할 수 있습니다.

자동 검증은 목표 상태의 저장 유효성, 세션 예산, 300개 회로 풀이, 이전 해금 보존, 세 게임 백업/복원과 그림 도감을 확인합니다. 실제 클릭/사고 시간과60일 장기 체험은 추후 플레이 관찰로 확인할 항목입니다.
