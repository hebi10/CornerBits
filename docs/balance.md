# v0.6.0 진행량 모델

정원·낚시·검 키우기를 각 하루10~15분씩 즐기며 주요 목표를 약60일에 달성하도록 구성했습니다. 일일 제한은 없습니다. `npm run balance`는 실제 reducer를 사용하는 계산이며, 실제 사람의60일 체험을 측정한 결과는 아닙니다. 신규 시작 기준이고 기존 정원은 보존한 진행도에서 이어집니다.

| 하루 게임별 시간 | 낚시 방문 일 | 정원 방문 일 | 검100시드 중앙 예상 일 |
|---|---:|---:|---:|
| 10분 | 73 | 67 | 75.58 |
| 12.5분 | 58 | 58 | 60.46 |
| 15분 | 48 | 49 | 50.39 |

표의 시간에는 입질·성장·연마 대기를 포함합니다. 계속 클릭하는 순수 능동 조작 시간은 이보다 짧습니다. 세션 길이와 실제 반응·선택·접속 패턴·강화 운에 따라 달라집니다. 낚시15분 모델은48일로, 모든 일정이60일에 끝난다는 뜻은 아닙니다.

## 낚시

주요 목표1,500마리·36종·낚싯대8단계입니다. 장비1단계는18~30초 대기와5초 반응 여유이며, 강화마다 대기0.5초 단축·반응 여유1초 증가로8단계는14.5~26.5초 대기와12초 반응 여유입니다. 이미 저장된 진행 중 낚시의 시각·어종·난수는 바꾸지 않습니다. 물고기는 보관했다가 일괄 판매하며 빠른 반응은 추가 판매가를 붙입니다. 판매해도 누적 마릿수·도감·전시3종은 유지합니다. 기본 미끼는 무료이고, 풀잎/반짝 미끼는5개에50/150코인으로 구매해 던질 때1개씩 소비합니다. 실패해도 사용한 미끼는 반환하지 않습니다. 희귀 어종 비중은 기본/풀잎/반짝 미끼가7/12/27%입니다.

6지역마다6종을 모읍니다. 다음 지역은 누적70/220/450/800/1,200마리와 직전 지역4종 수집을 함께 만족하면 영구 개방합니다. 각 지역25번째 성공에서는 미발견종을 우선해 컬렉션 천장을 둡니다.

모델은 하루 한 번 방문, 던지기1초·입질 후 반응1초·당기기1초,20번 중2번 일부러 늦게 놓치는10% 실패를 가정합니다. 코인이 부족하거나 방문이 끝날 때 보관한 물고기를 판매하고, 낚싯대 강화에 우선 지출한 뒤 반짝 미끼를5개씩 구매합니다. 구매할 코인이 없으면 무료 기본 미끼를 사용합니다. 한 지역의 도감을 채운 뒤 다음 열린 미완성 지역으로 이동합니다. 판매·구매·미끼/지역 선택·강화도 각각 입력1초로 셉니다. 현재 장비의 최대 대기+반응 여유+당기기 입력1초를 남겨 두고 던지며, 준비 행동은 그보다1초 더 남을 때 시작합니다. 준비 중 강화한 경우 바뀐 장비로 예산을 다시 확인합니다. 모든 낚시는 방문 안에 정산하고 오프라인 자동 수집은 없습니다.

12.5분 모델에서58일,1,668회 던져1,500마리 성공·168회 놓침,36종·낚싯대8단계·6지역을 달성합니다. 입력62.42분·입질 대기633.50분·세션 잔여23.43분이며, 판매64회·미끼 묶음 구매333회·지역 이동5회·강화7회가 포함됩니다. 마지막 코인은56,806입니다. 선택 행동은 세지만 메뉴 판독·화면 전환에 걸리는 시간은 별도로 가정하지 않습니다. 강화로 기다림이 줄고 반응 여유가 늘어난 효과를 실제 reducer에 반영한 계산입니다.

## 정원

목표40종 직접 수확·화분12개입니다. 기본 성장60/90/120/이후180초, 물주기는25%를 줄입니다. 다음 씨앗을 열기 위한 직전 품종 수확은 씨앗 번호2/3/4/5~9/10~21/22~40에 대해5/12/20/50/90/120회입니다. 영구 해금 수를 저장하므로 이전판에서 열린 씨앗이 다시 잠기지 않습니다.

하루 한 번 방문에서 성공 행동마다1초, 수확·확장·최신 해금 씨앗 심기·물주기를 반복합니다. 예산이 남을 때만 다음 행동을 시작하고 오프라인 성장도 계산합니다.12.5분 모델58일, 전체 입력201.27분·성장 대기521.08분, 하루 평균 입력3.47분입니다. 씨앗 선택과 화면 판독은 별도 시간으로 가정하지 않습니다.

## 검 키우기

주요 목표+60이며6단계마다 외형이 바뀝니다. 연마는10초 간격, 기본재료20개·조준 성공28개입니다. 일반 강화 비용은40+현재단계×3입니다. 현재0~9/10~19/20~29/30~39/40~49/50~59단계에서 성공80/40/20/10/5/2%입니다.39회 연속 실패 후 다음 일반 강화는100%입니다. 실패해도 검은 유지되고 조각1개를 얻습니다. 안정 강화는 일반재료 비용3배와 조각10+3×floor(단계/10)를 사용해100% 성공합니다.

모델은 성공 입력1초, 연마4회 중1회 조준, 외형이 바뀌는6단계마다 조각이 있으면 안정강화(이미 보정30 이상이면 일반)를 선택합니다. 실제 reducer를100개 시드로 실행한 중앙은755.78분으로,12.5분씩이면60.46일입니다.10~90백분위51.28~68.40일, 전체43.92~79.05일입니다. 표는 중앙값이고 모든 플레이가60일에 끝난다는 뜻은 아닙니다.

입력 평균83.35분, 연마 쿨다운/조준 대기 평균671.74분입니다. 모델의 순수 입력은 세션당 약1.38분이며 나머지는 대기입니다. 오프라인 재료 자동 생성은 없으며, 모델은 연속 조작의 누적 시간을 계산한 뒤 일일 시간으로 나눈 추정입니다. 실제 방문 경계에서는 다음 연마까지의10초 대기가 접속 사이에 끝날 수 있습니다.

## 저장과 검증

schema7은 정원·낚시·검과 숨겨 보관한 광산·회로 데이터를 함께 저장합니다. 전시 어종 keepsakes는 최대3개이며 유니크한0~35 인덱스와 도감 수집 여부를 엄격히 확인합니다. 새 어획을 앞에 넣고 중복을 제거하며 판매 후에도 유지합니다. 전시36어종 전용 그림·6지역 풍경·8장비 그림은 기록을 표시하고, 장비의 실제 대기/반응 효과는 새 던지기에 적용됩니다.

v1~v6 이전은 정확한 원본 스냅샷부터 보존하며 원본 보존 실패 시 변환하지 않습니다. v6의 모든 기존 필드·설정·저장번호·시각·활성 입질·난수를 그대로 유지하고 발견 어종 인덱스 역순 최대3개로 전시만 추가합니다. 이전 기록에는 어획 순서가 없으므로 복원된 전시를 과거 최근 순서로 간주하지 않습니다. v5의 코인·도감·활성 입질·난수와 기존 게임 수치도 유지합니다. 이전 낚시는 잡는 즉시 코인을 지급했으므로 이미 잡은 물고기는 판매 재고로 다시 지급하지 않으며, v5에서 오는 새 재고·판매 보너스·유료 미끼 재고는0입니다. 기존 누적 마릿수와 현재 위치를 기준으로 열린 지역을 보존합니다. v1~v4는 낚시·검이 처음 상태로 추가됩니다. 진행 중 낚시의 종/입질 시각과 검의 난수 상태도 유지해 재시작이 재추첨으로 이어지지 않습니다. 전시·판매·구매·소모를 포함한 모든 주요 행동은 자동 저장/통합 백업에 포함됩니다.

이전 광산/회로 엔진과 모델은 레거시 회귀 검증용으로 남아 있습니다. 현재 `npm run balance`가 보고하는 대상은 낚시·정원·검 세 게임입니다.
