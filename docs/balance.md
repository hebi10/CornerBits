# v0.4.0 진행량 모델

정원·낚시·검 키우기를 각 하루10~15분씩 즐기며 주요 목표를 약60일에 달성하도록 구성했습니다. 일일 제한은 없습니다. `npm run balance`는 실제 reducer를 사용하는 계산이며, 실제 사람의60일 체험을 측정한 결과는 아닙니다. 신규 시작 기준이고 기존 정원은 보존한 진행도에서 이어집니다.

| 하루 게임별 시간 | 낚시 방문 일 | 정원 방문 일 | 검100시드 중앙 예상 일 |
|---|---:|---:|---:|
| 10분 | 77 | 67 | 75.58 |
| 12.5분 | 61 | 58 | 60.46 |
| 15분 | 51 | 49 | 50.39 |

표의 시간에는 입질·성장·연마 대기를 포함합니다. 계속 클릭하는 순수 능동 조작 시간은 이보다 짧습니다. 세션 길이와 실제 반응·선택·접속 패턴·강화 운에 따라 달라집니다.

## 낚시

주요 목표1,500마리·36종·낚싯대8단계입니다. 입질은18~30초 뒤 오며5초 안에 당깁니다. 빠른 반응은 코인 보상을 늘립니다. 미끼3가지의 종별 가중치가 다르고,6지역마다6종을 모읍니다. 각 지역25번째 성공에서는 미발견종을 우선해 컬렉션 천장을 둡니다. 미끼와 던지기는 무료이고 실패는 재화 손실이 없습니다.

모델은 하루 한 번 방문, 던지기1초·입질 후 반응1초·당기기1초,20번 중2번 일부러 늦게 놓치는10% 실패를 가정합니다. 미끼2를 사용하고, 한 지역의 도감을 채운 뒤 다음 열린 지역으로 이동하며 가능한 강화를 합니다. 세션 잔여37초 미만이면 새 낚시를 시작하지 않아 모든 낚시를 방문 안에 정산합니다. 오프라인 자동 수집은 없습니다.

12.5분 모델에서61일,1,668회 던져1,500마리 성공·168회 놓침, 입력55.82분·입질 대기679.51분·세션 잔여23.33분입니다. 서로 다른3시드 모두61일을 확인했고,15% 놓침 가정은65일입니다. 선택/메뉴 판독 시간은 별도로 가정하지 않습니다.

## 정원

목표40종 직접 수확·화분12개입니다. 기본 성장60/90/120/이후180초, 물주기는25%를 줄입니다. 다음 씨앗을 열기 위한 직전 품종 수확은 씨앗 번호2/3/4/5~9/10~21/22~40에 대해5/12/20/50/90/120회입니다. 영구 해금 수를 저장하므로 이전판에서 열린 씨앗이 다시 잠기지 않습니다.

하루 한 번 방문에서 성공 행동마다1초, 수확·확장·최신 해금 씨앗 심기·물주기를 반복합니다. 예산이 남을 때만 다음 행동을 시작하고 오프라인 성장도 계산합니다.12.5분 모델58일, 전체 입력201.27분·성장 대기521.08분, 하루 평균 입력3.47분입니다. 씨앗 선택과 화면 판독은 별도 시간으로 가정하지 않습니다.

## 검 키우기

주요 목표+60이며6단계마다 외형이 바뀝니다. 연마는10초 간격, 기본재료20개·조준 성공28개입니다. 일반 강화 비용은40+현재단계×3입니다. 현재0~9/10~19/20~29/30~39/40~49/50~59단계에서 성공80/40/20/10/5/2%입니다.39회 연속 실패 후 다음 일반 강화는100%입니다. 실패해도 검은 유지되고 조각1개를 얻습니다. 안정 강화는 일반재료 비용3배와 조각10+3×floor(단계/10)를 사용해100% 성공합니다.

모델은 성공 입력1초, 연마4회 중1회 조준, 외형이 바뀌는6단계마다 조각이 있으면 안정강화(이미 보정30 이상이면 일반)를 선택합니다. 실제 reducer를100개 시드로 실행한 중앙은755.78분으로,12.5분씩이면60.46일입니다.10~90백분위51.28~68.40일, 전체43.92~79.05일입니다. 표는 중앙값이고 모든 플레이가60일에 끝난다는 뜻은 아닙니다.

입력 평균83.35분, 연마 쿨다운/조준 대기 평균671.74분입니다. 모델의 순수 입력은 세션당 약1.38분이며 나머지는 대기입니다. 오프라인 재료 자동 생성은 없으며, 모델은 연속 조작의 누적 시간을 계산한 뒤 일일 시간으로 나눈 추정입니다. 실제 방문 경계에서는 다음 연마까지의10초 대기가 접속 사이에 끝날 수 있습니다.

## 저장과 검증

schema5는 정원·낚시·검과 숨겨 보관한 광산·회로 데이터를 함께 저장합니다. v1~v4 이전은 정확한 원본 스냅샷부터 보존합니다. 진행 중 낚시의 종/입질 시각과 검의 난수 상태도 유지해 재시작이 재추첨으로 이어지지 않습니다. 모든 주요 행동은 자동 저장/통합 백업에 포함됩니다.

이전 광산/회로 엔진과 모델은 레거시 회귀 검증용으로 남아 있습니다. 현재 `npm run balance`가 보고하는 대상은 낚시·정원·검 세 게임입니다.
