# 장식형 도트 낚시 개편

해비님은 체험 분석의 방향을 승인하고 낚시부터 수집·장비·지역 변화가 느껴지게 개편하며, 전체 UI를 얼핏 장식처럼 보이는 미니멀한 흑백 도트로 바꾸도록 요청했다.

## 방향과 범위

투명 바탕 위에 작은 낚시 장면과 수집한 물고기 세 마리를 둔다. 평소 숫자·제목·저장 완료 문구를 줄이고 조작 가능한 작은 그림과 접근성 이름을 유지한다. 메뉴 안에는 판매/구매/도감의 현재 용무를 나눠 표시한다. 큰 사각 배경·얼굴·귀여운 장난감 표현·색상은 넣지 않는다.

별도 대시보드나 전체 배경을 만드는 방식은 사용자가 요청한 투명한 장식의 방향과 맞지 않는다. 기존 배 한 장의 문구만 줄이는 방식은 수집/장비/지역 체감 문제를 해결하지 못한다. 현재 Tauri/React와 저장 구조를 확장하는 작은 장면 방식을 채택한다. 앞선 분석과 이번 직접 지시로 구현 방향이 승인됐으며, 세부 크기와 아래 수치는 구현 판단이다.

## 낚시 규칙과 영속성

- schema7에 fishing.keepsakes를 추가한다. 서로 다른 어종 최대3개이며 해당 caught 값이 양수인 정수 인덱스만 허용한다. 새 어획을 앞에 넣고 중복을 제거해3개만 남긴다. 판매 후에도 유지한다. v6 이전은 기존 도감에서 최대3종을 골라 전시하고 기존 모든 필드를 보존한다. v1~v5도 기존 경로를 거쳐 이전한다.
- 장비1~8은 새 던지기의 입질 대기를 단계마다500ms 단축하고 입질 반응 시간을5~12초로 늘린다. 저장된 진행 중 낚시의 종/시각/RNG를 다시 계산하지 않는다. 장비별 실제 효과를 메뉴에서 확인할 수 있다. 별도의 장비 그림으로 단계를 구별한다.
- 수집·판매·미끼·지역 해금은 기존 규칙을 유지한다. 지역6곳은 투명한 최소 풍경 자산으로 구분한다. 어종36개는 각각 식별할 수 있는 실루엣을 사용한다. 지역 변경은 기존 진행 중 낚시 제한을 유지한다.
- 주요 목표1500마리·36종·장비8, 일일 제한 없음과 하루10~15분/약60일 방향은 유지한다. 실제 강화 효과와 상점 행동을 포함해 엄격한 세션 모델을 다시 계산하고 추정과 실제 체험을 구분한다.

## 화면과 검증

- 물고기 전시는 어종 툴팁·접근성 이름을 제공하고 누르면 도감을 확인할 수 있다. 희귀/신규 어획은 큰 글자 대신 짧은 그림 신호와 구체적인 결과를 제공한다.
- 메인에서 장면을 유지하고 상점/도감 등 명시적 조작 시만 필요한 UI를 표시한다. 평소 저장 상태는 작은 표시로 줄이되 오류/저장 중/재시도/복원 경고는 감추지 않는다. 제목 드래그·축소·키보드·모션 감소/숨김을 유지한다.
- 정원과 검의 게임 규칙은 유지하고 공통 그림/글자/메뉴의 크기·간격과 대비를 정리한다. 보관함의 데이터 보호 기능과 네이티브 셸 정책은 유지한다.
- TS/Rust 엄격한 schema7 검증·v6 원본 선행 스냅샷/실패 원본 보존·진행/재실행/통합 백업·복원을 확인한다. 밝은/어두운280×380에서 그림/메뉴/오류/최대 상태를 확인한다. 새 이미지 생성 원본과 프롬프트를 보존한다.
- 새 의존성·브랜치·worktree·삭제·푸시·배포를 추가하지 않는다. Computer Use 없이 브라우저/자동 테스트와 사용자 수동 Windows 확인을 사용한다. 완료 시 로컬 커밋한다.
