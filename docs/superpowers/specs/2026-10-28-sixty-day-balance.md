# 세 게임의 약 60일 진행과 정원 도감

해비님은 각 게임을 하루 10~15분씩 즐기며 주요 목표를 약 60일에 달성하기를 원한다. 일일 제한 없이 플레이량으로 조정하는 방식을 선택했다. 더 오래 하거나 빠르게 풀면 먼저 완료할 수 있다.

- 기준 목표: 광산 1,000층·광물 30종·곡괭이 10단계, 정원 40종 직접 수확·화분 12개, 회로 300개 완료. 실제 사람의 60일 플레이를 검증한 것으로 표현하지 않는다.
- 대기 위주의 정원은 짧은 성장과 반복 가꾸기로 조정한다. 해금 수확 요건과 확장 비용은 첫 체험을 유지하면서 점진적으로 늘린다. 시뮬레이션은 10/12.5/15분 세션, 입력·선택 시간과 대기를 구분한다.
- 광산은 타격뿐 아니라 판매·강화·이동 시간까지 계산한다. 회로는 고정 생성기와 기존 퍼즐을 바꾸지 않고 조작량·사고 시간의 가정을 공개한다. 튜닝 결과와 가정은 별도 실행 가능한 분석으로 보존한다.
- 기존 진행·중간 회전·채굴 칸·심은 시각·재화는 보존한다. 정원 영구 해금 수를 추가할 경우 schema4로 이전하며, 이전 버전에서 열린 씨앗이 다시 잠기지 않게 한다. 원본 스냅샷을 먼저 보관하고 실패 시 원본을 유지한다.
- 첨부한 정원 도구/도감은 긴 문장과 중첩 스크롤을 작은 그림 도감으로 바꾼다. 씨앗 선택·도감·확장 조작을 구분하고, 현재 품종/다음 목표만 간결하게 표시한다. 현재 투명 흑백 장식 세계와 생성 PNG를 사용한다. 큰 사각 배경이나 새로운 이미지 제작은 필요하지 않다.
- 자동 저장·백업/복원·트레이·드래그 동작을 유지한다. Computer Use 없이 자동 검증하고 실제 Windows 조작은 사용자에게 요청한다. 로컬 커밋만 생성한다.

검토한 대안: 일일 제한은 사용자가 선택하지 않았다. 기존 장시간 성장만 조정하는 방식은 10~15분의 활동량을 만들지 못한다. 선택한 방식은 제한 없이 짧은 플레이 루프와 단계적 해금으로 분량을 조정하는 것이다.

확정 수치: 광산 강화는 현재 단계×40층 및 단계²×500코인이다. 정원 성장60/90/120/180초, 다음 씨앗 수확 요건5/12/20/50/90/120회이며 schema4 영구 해금 수를 보존한다. 회로300개 생성기는 유지하며 작은 회로6~7개·큰 회로4개를 일일 권장량으로 안내한다. `npm run balance`의 실제 reducer 모델에서 하루12.5분은 광산59.23일·정원58일·회로57.61일이다. 정원의 순수 입력은 평균3.47분/일이고 나머지는 성장 대기다. 회로 사고 시간은4×4에서90초·5×5에서155초 가정이며 실측이 아니다. 상세 모델은 `docs/balance.md`에 기록한다.
