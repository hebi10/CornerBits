# 단색 게임 이미지와 움직임

사용자가 위젯 동작은 정상이라고 확인한 뒤, 텍스트 중심 화면이 재미없어 보이므로 이미지를 많이 활용하고 어느 정도 동적으로 보이는 단색 꾸밈 요소를 요청했다.

기존 흑백 디자인,280×380 위젯,게임 규칙·경제·저장·백업을 유지한다. 글자격자 대신 생성한 실제 PNG 스프라이트로 광석과 식물을 표현한다. 새 라이브러리와 SVG 그림을 추가하지 않는다. 작은 픽셀 미니어처 느낌의 광산/정원4×4 아틀라스 두 장을 생성해32개 그림을 재사용한다. 아틀라스는 이미지 편집 없이 CSS 위치로 표시한다.

- 광산: 온전한 광석/금간 광석/빈 채굴 자리를 구분하고, 곡괭이·광차·동전·랜턴으로 분위기를 만든다. 클릭 시 짧은 타격/파편/획득 반응. 반복된 광물명·내구도 숫자는 셀에서 줄이고 접근성 이름·도움말로 유지한다.
- 정원: 빈 화분·심은 씨앗·새싹·어린 식물·성숙 식물을 성장 비율에 따라 보여준다. 이름과 핵심 동작은 작은 레이블로 보존한다. 물주기/수확 피드백과 조용한 잎 움직임.40종은12개 식물 그림 계열을 재사용하며 그림이 개별 종의 식물학적 묘사라고 주장하지 않는다.
- 움직임은 기능 피드백과 작은 장식에 한정한다. 숨긴 문서·컴팩트/다른 게임에서는 중지하고 reduced-motion에서 움직임을 제거하되 상태는 남긴다. 소리와 밝은 색/반짝임은 없다.
- 생성 PNG와 정확한 프롬프트/생성경로를 저장하고 도구 출력을 그대로 사용한다. 이미지 생성 결과를 확인한 뒤 실제280×380 렌더링,게임/백업회귀,Windows빌드로 검증한다.

사용자가 이미지 중심 단색 표현을 직접 요청했으므로 기존 무애니메이션 기본값을 위 범위에서 변경한다. 구현 방식은 기존 컴포넌트와 생성 래스터 자산을 확장하는 것으로 정했다.

## v0.1.2 확인 후 추가 방향

사용자는 새 그림 버전의 동작은 정상이라고 확인했지만 디자인 변경을 더 요청했다. 두 방향 중 **바탕화면 장식처럼 배경과 테두리를 최소화하고 광산·화분 그림 위주로, 메뉴와 숫자는 작게**를 선택했다.

게임 화면의 큰 사각 바탕을 투명하게 하고, 광산 판의 배경/테두리를 없애며 그림을 확대한다. 메뉴·저장 표시는 작은 조작부로 줄인다. 밝고 어두운 배경 모두에서 글자를 읽을 수 있도록 글자 바로 뒤의 작은 중성 배경만 유지한다. 정원은 화분을 먼저 보여주고 씨앗/확장 도구를 아래에 배치한다. 백업 관리·오류·도감 펼침에는 읽기 쉬운 배경을 유지한다. 기존 PNG,게임규칙,저장,280×380크기,네이티브배치에는 변경이 없다.
