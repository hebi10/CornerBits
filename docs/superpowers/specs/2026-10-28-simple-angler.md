# 낚시꾼 중심의 단순한 낚시 화면

사용자가 현재 도트 낚시 화면을 보고 낚시꾼도 있으며 더 단순하게 바꾸기를 요청했다.

- 바위·독립 낚싯대·어항·물고기·강화 아이콘을 나열한 메인 화면을 하나의 연결된 낚시꾼 장면으로 바꾼다. 낚시꾼은 표정 없는 흑백 픽셀 인물이며 작은 도크/땅끝에 앉아 오른쪽으로 낚시한다.
- 신규2×2 투명 PNG는 idle/waiting/bite/catch의 네 상태를 같은 위치/배율로 표현한다. 기존 자산은 보존한다.
- 메인 조작은 장면을 누르는 버튼 하나와 작은 도구 메뉴다. 미끼·낚시터·강화·도감은 메뉴 안에 모은다. 평소 설명/지명은 툴팁·접근성 이름으로 제공하고, 대기/입질/결과만 작은 상태 줄에 표시한다.
- 낚시 규칙·확률·분량 모델·저장/백업은 유지한다. 입질/포획 장면 전환은 실제 저장된 낚시 상태와 확인된 결과에 맞춘다. 모션 감소/숨김과 키보드 접근성을 유지한다.
- 동일한280×380 위젯 안에서 밝고 어두운 바탕·도구 메뉴·캐스트/입질/포획·재실행을 검증하고,Windows 실행파일로 교체한다. Computer Use와 사용자 파일 삭제는 하지 않는다.

구현 결과: 새 장면/메뉴 구성과4상태 전환을 반영했다.270단위/35브라우저/타입체크/Windows제품빌드와10화면 검증을 통과했다. 실제 실행 후 기존 기록 전체 보존 확인, 사용자 조작/구성 답변 대기 중. 소스와 새자산은 로컬 커밋으로 보존한다.
