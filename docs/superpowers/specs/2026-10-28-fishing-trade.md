# 배 낚시와 판매·미끼·지역 성장

해비님은 낚시꾼이 배에 타고, 잡은 물고기를 팔고 좋은 미끼를 구입해 좋은 어종을 모으며 일정 수준에 도달하면 다른 지역으로 가는 흐름을 요청했다.

- 벤치를 작은 배로 교체한 흑백 도트4상태 장면을 사용한다. 메인은 배와 낚시꾼만 누르는 단순함을 유지한다.
- 물고기는 잡을 때 판매 재고에 들어간다. 기본 판매가는12+지역×8+지역내어종×12코인이다. 빠른 반응 보너스는 재고의 추가 판매가로 보관하며 판매할 때 코인으로 정산한다.
- 기본 미끼는 무료 무제한이다. 두 유료 미끼는5개 묶음50/150코인이며 던질 때1개씩 사용한다. 희귀 두 어종 비중은 기본7%·유료12%/27%다. 선택·재고·가격을 표시하고 부족하면 기본 미끼로 바꾸거나 구매할 수 있다.
- 다음 지역은 기존 누적량70/220/450/800/1200마리와 직전지역4종 이상 수집으로 열린다. 한 번 열린 지역은 영구 보존하며 자유롭게 이동한다. 기존 지역 해금과 재화/도감도 이전한다.
- 상점·판매·도감은 작은 메뉴 안에 둔다. 진행 중에도 입질 상태를 확인할 수 있게 하며, 지역/미끼 변경과 구매는 진행 중 낚시의 조건을 바꾸지 않는다. 판매·구매·소모·수집·영구 지역은 모두 자동 저장/백업에 포함한다.
- schema6은 inventory36개/inventoryBonus/baitStock2개/unlockedLocations를 낚시에 추가한다. v5 이전 물고기는 이미 코인 정산됐으므로 새 판매 재고와 미끼는0으로 시작한다. 기존 코인·도감·입질/RNG는 그대로 보존하며 원본 스냅샷부터 보관한다. v1~v4 이전도 지원한다.
- 정원/검과 주요 목표1,500마리·36종·낚싯대8/일일 제한 없음은 유지한다. 판매/구매 입력을 포함한 실제 reducer 모델로 진행량을 다시 검증한다. 새 의존성·결제·서버·Computer Use·푸시/배포를 추가하지 않는다.
