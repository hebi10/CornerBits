# 2단계: 미니 광산과 작은 정원

사용자 요청: 기존 280×380 Windows 앱에 두 게임을 구현하고 게임 진행도를 자동 저장·백업·복원한다. 기존 기획의 게임별 하루 10~15분, 주요 목표 약 60일을 초기 조정 기준으로 삼는다. 매일 접속 의무, 소멸, 서버, 새 의존성은 없다.

## 구현 선택

기존 React 화면과 원자적 파일 저장을 확장한다. 별도 게임 엔진이나 게임별 저장 파일은 추가하지 않는다. 순수 TypeScript 게임 규칙, 게임별 화면, 통합 상태를 분리하여 기존 저장 큐가 한 행동마다 전체 상태를 보관한다. 이는 구현 판단이며 기존 개발 요청 범위에서 진행한다.

## 게임

- 광산: 5×5 블록 클릭, 남은 내구도 저장, 한 층을 모두 채굴하면 다음 층. 광물 일괄 판매, 깊이와 재화 조건을 갖춘 곡괭이 10단계. 목표 1,000층·광물 30종. 층/칸에 따른 확정 광물로 재실행 재추첨을 없앤다. 목표 후에도 기록 증가.
- 정원: 무료 씨앗, 시작 화분 3개, 최대 12개. 심기 → 한 번 물주기(성장 시간 25% 단축) → 수확. 시들지 않으며 앱 종료 중에도 성장. 40종, 직전 품종 5회 수확 시 다음 품종 해금. 첫 세 품종은 1분/5분/30분, 이후 6시간/32시간/48시간으로 확장한다. 수확 재화로 화분 확장. 미접속은 최대 화분당 한 번 성숙하며 자동 반복 수확은 없다.
- 광산은 1층 약 50회 채굴 입력을 초기 기준으로 하고, 정원은 짧은 관리와 오프라인 성장을 결합한다. 60일은 보장 시간이 아니며 시뮬레이션과 실제 플레이로 조정할 목표다. 정원에 10~15분을 강제하는 반복 클릭은 넣지 않는다.

## 화면

기존 흑백 색상과 정사각형 컨트롤을 유지한다. 상단에 광산 / 정원 / 관리 전환, 공통 저장 상태. 광산과 정원 주 조작은 작은 창 안에, 도감·설명·관리 내용은 세로 스크롤. 컴팩트·항상 위·트레이 동작 유지. 게임 입력은 준비/복원/저장 오류 때 잠근다.

## 상태 계약

AppState schemaVersion=2, 기존 revision/updatedAt/settings 유지, games={mine,garden} 추가. 백업 봉투 backupVersion=1 유지(내부 schemaVersion으로 식별).

MineState: depth(1..1,000,000), pickaxe(1..10), coins(0..10^12), inventory[30], collected[30], tiles[25], totalMined(0..10^12). 모두 정수. 광물 수량 각 0..10^12, inventory<=collected. 총 채굴 수는 collected 합. 내구도는 0..2*min(10,1+floor((depth-1)/100)). 처음 depth1, pickaxe1, tiles는 모두2, 나머지0.

GardenState: coins(0..10^12), pots[3..12] (null 또는 {species:0..39,plantedAt:0..8,640,000,000,000,000,watered:boolean}), harvested[40](각0..10^12), totalHarvests(0..10^12, harvested 합), lastObservedAt(같은 timestamp 범위). plantedAt<=lastObservedAt. 초기 coins0, pots null3개, harvested0, totalHarvests0,lastObservedAt0. 시계 역행 때 max(now,lastObservedAt) 사용, Date.now 기반의 오프라인 성장만 지원. 변경 행동에서 관측 시간 저장.

## 호환성과 보호

v1 설정과 백업은 검증 후 v2 빈 게임으로 변환한다. 네이티브 최초 변환 전에 원본 바이트를 pre-migration 스냅샷으로 보관하고, 스냅샷 실패 시 원본을 건드리지 않는다. 브라우저 미리보기도 별도 migration snapshot을 보관한다. v2 누락 필드·잘못된 길이·범위·합계·미래 버전은 거절한다. 기존 복원 전 백업과 원자적 쓰기를 유지한다. v1 백업 복원은 게임 초기화임을 확인 화면에 명시한다.

## 검증

게임 경제·수확·중복 입력·시계 역행·목표 도달 시뮬레이션, v1→v2 변환 및 원본 보존, v2 내보내기/복원/오류 격리, 저장 큐 깊은 복사, 실제 브라우저 게임 흐름과 280×380 화면, Rust 저장 테스트, Windows 실행 파일 빌드. 실제 네이티브 창 조작은 사용자 수동 확인.
