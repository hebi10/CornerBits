# 해안 생활 · 자원·집 성장·영구 저장

해비님이 A안 화면을 승인하고 낚시·채집 자원이 집 꾸미기와 성장으로 이어지며 진행도 자동 저장·백업/복원을 붙이도록 요청했다. 한 공간·컬러 픽셀·투명280×380 장면을 유지한다.

## 첫 성장 구간

- 낚시는 보관 물고기와 누적 어획을 늘린다. 물고기 걸이나 집 메뉴에서 전량 판매하면 한 마리15조개코인을 얻는다. 누적 어획은 남고 실제 보관량에 따라 걸이 그림이 바뀐다.
- 채집은 나무와 누적 채집량을 늘린다. 집1/2/3단계의 낚시·채집 보상은 각각1/2/3개다. 오프라인 반복 생성이나 실패 타이밍은 넣지 않는다.
- 집 메뉴에서 꽃화분(나무3/코인20,집1), 등불(6/45,집2), 벤치(12/90,집3)를 각각 한 번 제작한다. 장식은 비트1/2/4로 보관하며 선택 순서는 자유다. 집2 확장은나무12/코인75, 집3 확장은25/150이다. 비용은 시작 때 원자적으로 예약/차감하고 완료 때 장식 또는 집단계를 올린다. 중간 저장/복원 후 비용을 또 차감하지 않는다.
- 집 확장은 같은 섬/문/길/부두의 위치를 유지한 성장 그림으로 구분한다. 확장과 장식 사이에 재료를 어떻게 쓸지 선택할 수 있다. 현재 범위는 집3단계/장식3종의 첫 성장 구간이며60일 분량을 보장하지 않는다.

## 영구 상태 계약

schema8의 games에 coast를 추가하고 기존5게임·설정·저장번호·시각을 보존한다. v1~v7은 엄격한 원래 형태로 읽고 원본 스냅샷 선행 후 빈 해안 생활을 추가한다. v0.7 체험판의 세션 상태는 저장된 적이 없어 이관하지 않는다. 백업 봉투1·2MiB·UTF-8·원자 저장·복원 직전 스냅샷을 유지한다.

coast의 정확한9필드: activity(null/fish/gather/flower/lantern/bench/upgrade), elapsedMs, catches,totalGathered,fish,wood,coins,decoration,houseLevel. 숫자는 안전한 정수, 재화/누적 상한1e12, 보관fish<=catches/wood<=totalGathered,집1..3,장식0..7 및 집별 해금 범위를 검증한다. idle이면elapsedMs0, 진행 중은0<=elapsedMs<해당 왕복 시간, 완료된 장식의 중복 제작/최고집 확장/보상 상한 초과 진행을 거부한다.

실시간 애니메이션은 표시 상태만 전진한다. 행동 시작/완료·판매·일시정지/숨김/접기/메뉴·백업/종료 체크포인트에서 저장하고 매 tick 파일을 쓰지 않는다. 정지/접기는 실행 중 화면 상태이며 이전 설정 필드는 보존한다. 저장을 확인한 후 확정 보상과 성공 신호를 보이며 실패하면 조작/시간 진행을 잠그고 같은 스냅샷을 재시도한다. 닫기는 진행 중 작업과 체크포인트/저장을 기다리고 실패 시 닫지 않는다. 중간 행동은elapsedMs로 다시 시작하며 닫힌 시간 동안 추가 반복 보상이 생기지 않는다.

## 화면과 검증

평소에는 장면과 작은 저장 표시만 둔다. 집을 누르면 자원·3제작·집확장·판매를 읽기 쉬운 작은 창에서 고른다. 기록 메뉴에 백업 내보내기/가져오기/복원 확인/재시도를 둔다. 이전 백업 복원 시 해안 생활이 처음 상태로 돌아감을 안내한다. 모션 감소·정지·숨김·접기·키보드·기존 셸/드래그 정책을 유지한다.

TS/Rust 같은 계약, 실제 pending 작업 fixture, 자원/원자 비용/중복 방지/수치 경계, 이전 원본/실패 보존, 재실행/백업 왕복, 저장 실패 잠금·재시도·종료 경합을 검증한다. 밝고 어두운 실제 크기에서 성장/집/기록/복원 화면을 본다. 새 성장 그림은 내장 이미지 생성 기능을 쓰고 원본/정확한 프롬프트를 보존한다. 새 의존성·브랜치/worktree·삭제·푸시/배포·Computer Use를 추가하지 않고 완료 시 로컬 커밋한다.
