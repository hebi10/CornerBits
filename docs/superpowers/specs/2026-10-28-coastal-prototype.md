# 해안 생활 A안 · 실제 크기 움직이는 화면

해비님은 세 컨셉 중 A를 선택하고 시안처럼 하나의 공간에서 낚시·채집·집 꾸미기가 이어지게 하며 먼저 실제 크기의 움직이는 화면을 요청했다. 이것은 명시적으로 승인된 화면 프로토타입이며 장기 경제/저장 설계를 먼저 추가하지 않는다.

- 280×380 Windows 위젯의 투명 바탕 위에 색이 절제된 픽셀 해안·집·부두·나무·작은 배를 둔다. 기준은 제공한 A 컨셉 이미지이며, 폐기된 흑백/세 게임 탭 화면은 계승하지 않는다.
- 물결 반짝임·굴뚝 연기·인물 걷기/행동이 실제로 움직인다. 부두·해변·집의 세 공간을 누르며 별도 게임 화면으로 전환하지 않는다. 정보·메뉴는 장면보다 작게 둔다.
- 부두: 집에서 부두로 걸어가 짧게 낚시하고 물고기가 집 앞에 남는다. 해변: 걸어가 나무를 줍고 보관 장소에 쌓인다. 집: 모은 나무1개로 꽃화분→등불→벤치를 순서대로 배치한다. 세 꾸미기 뒤에는 완성 안내를 제공한다.
- 보상은 이동/행동이 끝난 후 한 번만 지급하고, 행동 중 다른 행동을 시작하지 않는다. 일시정지·숨김은 진행/움직임을 멈추며 모션 감소에서는 이동을 간소화한다. 키보드/툴팁으로 세 공간을 구별한다.
- 이번 반응은 세션 내 임시 상태이며 다시 열면 초기 화면이다. 이 사실을 안내에서 명확히 밝힌다. 기존 schema7·게임 데이터·백업·창 위치/트레이 정책을 보존하고 새 게임 저장 형식은 만들지 않는다.
- 기존 index.html과 앱은 회귀 확인용으로 보존한다. 별도 coast.html entry를 추가해 새 네이티브 기본 화면으로 지정한다. 같은 React/Tauri/Vite를 유지하며 새 의존성·브랜치·worktree·삭제·푸시·배포는 추가하지 않는다.
- 새 그림은 내장 이미지 생성 기능으로 제작하고 생성 원본/프롬프트/실제 alpha를 보존한다. SVG/수동 픽셀 그림으로 대체하지 않는다.
- 밝고 어두운 실제 크기 렌더·세 행동/자원 연결·정지/모션 감소/화면 맞춤·기존 저장 원본 유지·제품 빌드를 확인한다. Computer Use는 피하고 Windows 조작 확인은 해비님께 요청한다.

구현 판단: 걷기 약1초씩/행동2~3초, 첫 화면에서 몇 초 안에 반응을 확인하게 한다. 전체 게임 분량과 장기 저장은 화면 방향을 확인한 뒤 정할 사항이다.
