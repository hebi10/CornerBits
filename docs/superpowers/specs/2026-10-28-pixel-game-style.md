# 흑백 도트 게임 스타일

사용자 최신 요청은 귀여운 포인트를 제거하고 도트 형식의 게임으로 바꾸는 것이다. 이전의 웃는 얼굴·둥근 장난감·부드러운 일러스트 세계를 교체한다.

- 낚시·정원·검의 게임 규칙, 목표/진행량, schema5와 기존 기록을 유지한다.
- 네 개의 신규4×4 투명 PNG(낚시/검/정원/도구)를 내장 이미지 생성으로 제작한다. 거친 사각 픽셀 윤곽과 제한된 흑백톤, 표정 없는 실제 사물/식물/무기 형태를 사용한다. 기존 자산은 남긴다.
- CSS는 pixelated 렌더링과 정수 픽셀/steps 움직임으로 맞춘다. 회전/부드러운 장난감 흔들림을 줄이고, 읽을 수 있는 굴림체를 우선한다. 큰 배경·버튼 채움·그림자·둥근 카드·새 hover 효과를 추가하지 않는다.
- 메뉴·보관함·도구까지 같은 도트 스타일이며, 귀여운 인격화 문구와 외형 이름을 담백한 게임 용어로 정리한다. 새 폰트/패키지/게임 기능은 추가하지 않는다.
- 기존 브라우저 검증과 밝은/어두운 실제 렌더, Windows 실행파일로 확인한다. Computer Use 없이 사용자에게 마지막 표시 확인을 요청한다. 로컬 커밋만 생성한다.

구현 결과: 신규PNG4개,굴림체/steps모션,화면 문구/외형 이름 정리,270단위/33브라우저/제품빌드와22장시각검증을 완료했다. 독립검토에서P1/P2없음,실제실행후게임/설정/저장번호/시각보존확인. 사용자최종표시답변대기중이며구현은로컬커밋으로보존한다.
