# 정원·낚시·검 키우기 개편

해비님은 광산과 회로를 낚시와 확률형 검 키우기로 교체하고 정원까지 세 게임으로 개편하는 방향을 승인했다. 귀여운 흑백 투명 장식, 일일 제한 없이 각 게임 하루10~15분·주요 목표 약60일, 자동 저장과 백업을 유지한다.

## 게임

- 낚시: 무료로 던지고18~30초 뒤 입질,5초 안에 낚아채면 수집한다. 미끼3개와 낚시터6개 선택에 따라36종을 모은다. 타이밍은 보상에 반영하며 실패는 재화 손실 없이 재도전한다. 각 지역25번째 성공에서는 미발견종을 우선해 수집 천장을 둔다. 목표는1,500마리·36종·낚싯대8단계. 중간 해금과 낚싯대 강화로 장기 성장을 만든다.
- 검: 큰 검을 연마해 재료를 얻고 확률 강화 또는 조각을 쓰는 확정 강화를 선택한다. 검 파괴/하락은 없으며 실패는 조각과 보정으로 이어진다. 일반 강화 확률과 비용, 보정 상태, 확정 강화 비용을 공개한다. 목표+60. 연마 간격과 재료 경제는 실제 reducer/여러 난수 시드 모델로 조정한다.
- 정원: v0.3.0의 짧은 성장/영구 해금/작은 그림 도감을 유지한다. 40종 수확과 화분12개가 목표다.

## 표현

기존 Sprite/CSS 패턴과 PNG 자산을 사용한다. 새 낚시·검 atlas는 내장 이미지 생성 기능으로 만들며 실제 투명 알파를 유지한다. 그림을 직접 누르는 조작, 이름/수치 툴팁과 작은 도감, 짧은 성공 효과를 사용한다. 큰 흰 판·상시 텍스트 버튼·그림자·새로운 둥근 패널·불필요한 마우스 오버 효과를 추가하지 않는다. 280×380/축소36px/키보드/모션 감소와 숨김 시 정지를 유지한다.

## 저장

schema5의 games는 `{mine,garden,circuit,fishing,sword}`다. 표시되는 게임은 낚시·정원·검의3개이며, 기존 광산·회로 데이터는 백업 안에 보존한다. v1~v4를 strict하게 읽어 기존 필드를 그대로 이전하고 새 게임만 초기화한다. 원본 스냅샷이 성공한 뒤 교체하며 실패 시 원본을 유지한다. 백업 봉투1을 유지한다. 진행 중 낚시의 종/입질 시각, 검의 난수 상태도 저장하므로 재시작으로 결과를 다시 뽑지 않는다.

일반 강화는 저장한 xorshift32를 전진해 결정한다. 확정 강화는 RNG를 소비하지 않는다. 타이머 표시는 저장하지 않고, 성공적인 행동과 결과만 기존 직렬 SaveQueue를 통해 저장한다. 네이티브 저장 실패 시 추가 행동을 잠그고 재시도한다.

## 검증과 범위

진행 모델은 입력·입질/연마 대기·생각 시간과 난수 가정을 구분한다. 실제60일 장기 플레이로 표시하지 않는다. 엔진 경계/천장/재화/난수/일시 중단, 기존 데이터 원본 보존, 새 세 게임 저장·백업 왕복, 그림 UI와Windows 실행을 검증한다. 새 의존성·서버·결제·출석 제한은 추가하지 않는다. 사용자 PC 조작은 Computer Use 대신 직접 확인을 요청한다. 로컬 커밋만 생성한다.
