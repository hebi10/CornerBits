# CornerBits phase one Implementation Plan

> **For agentic workers:** Use independent module implementers and a fresh final reviewer. No subagent commits, pushes, branches, worktrees, or deployment.

**Goal:** A small Windows application with reliable autosave and backup export/restore.

**Architecture:** Pure state/backup validation and serialized saves in TypeScript; filesystem/dialog/window integration in Tauri/Rust; one monochrome React screen.

**Tech Stack:** Tauri 2, React, TypeScript, Vite, Vitest, Playwright.

**Spec:** ../specs/2026-10-28-phase-one-design.md

## Global Constraints

- No games, accounts, network services, publishing, destructive cleanup, branches or worktrees.
- UTF-8. Black/gray interface. No shadows or rounded decoration. Font size at most 34px and weight at most 700.
- Malformed files never overwrite valid data. Native failures never fall back to browser storage.
- Work directly in the empty user-selected project. Initialize local Git for the user-required final commit without creating a separate development branch.

## Review Focus

Concurrent autosaves and restores; close during a pending write; corrupted or future data; disk replacement failures; off-screen and compact window recovery.

### Task 1: State and backup domain

Files: src/core/state.ts, src/core/state.test.ts. Produce AppState, initialState(), parseState(), encodeBackup(), decodeBackup(), and SaveQueue. Test rejection of malformed/future/oversized files and serialized writes/retry before implementation.

- [x] Verify failing domain tests, implement, then verify passing tests.

### Task 2: Native persistence and desktop shell

Files: src-tauri/**. Implement the spec's five commands and durable disk snapshots/atomic writes; native tests use temporary directories. Configure 280×380 window, tray, single instance, position persistence, restricted permissions.

- [x] Implement native commands, recovery snapshots, atomic writes, window/tray behavior and regression test sources.
- [x] Run native persistence tests and standalone debug/release builds. User disabled Smart App Control, the missing C++ compiler was supplied from official packages, and all 19 native tests passed. See ../../verification.md.

### Task 3: UI and integration

Files: src/App.tsx, src/platform.ts, src/style.css, src/main.tsx, tests/**. Integrate queued autosave, visible failures, backup dialogs and inline restore confirmation. Verify reload persistence and export/import roundtrip in browser and native smoke test.

- [x] Typecheck, unit tests, browser tests, production frontend build and 280×380 visual inspection.
- [x] Native smoke test. Launch release executable; user confirmed backup export/restore and settings persistence after closing and relaunching. Native data and the pre-restore snapshot were independently compared. Additional tray/multiple-monitor interactions remain outside this smoke test.
- [x] Fresh final review, resolve material defects, document validation, create local Git commit. No push/deployment.
