# 단색 게임 이미지 실행 계획

Spec: ../specs/2026-10-28-game-art-design.md

1. 메인이 내장 이미지 생성 도구로 광산/정원4×4 아틀라스를 병렬 생성·검사하고 public/art에 보존한다. 프롬프트 출처를 기록한다.
2. 광산·정원 화면 담당은 각각 독립 컴포넌트/CSS만 변경한다. 메인은 공유Sprite,visibility/motion처리와 상단상태밀도를 조정한다. 게임 규칙/데이터형식은 그대로.
3. 이미지 디코딩/배치,키보드/마우스게임흐름,reduced-motion,숨김중지,280×380과12화분상태를 확인한다. 실제이미지와화면을읽고독립시각검토한다.
4. 기존단위/E2E/타입·제품빌드 회귀 확인,Windows실행파일빌드,사용자확인,검증기록과로컬커밋. 네이티브위젯코드는변경하지않는다.

v0.1.2는 검증·사용자 동작 확인·로컬 커밋을 마쳤다. 후속 v0.1.3에서는 승인된 장식 방향에 맞춰 메인이 공용 셸/메뉴,각 담당이 겹치지 않는 게임 컴포넌트/CSS를 조정한다. 밝고 어두운 배경의280×380렌더와최대화분을검토하고,회귀테스트·정식빌드·실제사용자확인후별도커밋한다.
