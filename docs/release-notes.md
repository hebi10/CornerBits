# CornerBits · 해안 생활

Windows 10/11 x64에서 사용하는 작은 바탕화면 위젯입니다.

- **권장:** `CornerBits_버전_x64-setup.exe`를 받아 설치합니다. 관리자 권한 없이 현재 사용자에게 설치하며, WebView2가 없으면 설치 중 인터넷으로 준비합니다.
- **압축 실행본:** `CornerBits_버전_windows-x64.zip`을 풀고 `cornerbits.exe`를 실행합니다. WebView2 Runtime이 필요합니다.
- `SHA256SUMS.txt`로 받은 설치 파일과 ZIP의 SHA-256을 확인할 수 있습니다.

부두와 해변을 눌러 낚시·채집을 맡기고, 물고기를 판매해 집을 꾸미고 확장합니다. 다른 앱을 사용하거나 위젯을 접어도 작업은 이어지며, 작업 시간과 누적 획득량을 표시합니다. 위쪽 여백으로 이동하고, 트레이에서 위젯을 찾거나 종료할 수 있습니다.

진행도는 이 PC에 자동 저장됩니다. 위젯의 **기록**에서 백업을 내보내거나 복원할 수 있습니다. 앱을 교체해도 같은 저장 위치를 사용하며, 이전 저장 형식은 원본을 먼저 보관한 뒤 이관합니다.

이번 배포 파일에는 Windows 코드 서명이 포함되어 있지 않습니다.
