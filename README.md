# CornerBits

바탕화면 한쪽에 놓는 작은 Windows 위젯입니다. v0.6.0은 작은 배·지역 풍경·수집한 물고기가 남는 미니멀한 흑백 도트 낚시와 정원·검 키우기를 제공합니다. 평소 글자와 메뉴를 줄여 작은 장식처럼 두고, 주요 행동은 자동 저장하며 통합 백업·복원합니다. 배경화면 위·다른 프로그램 뒤에 머물며 작업 표시줄과 Alt+Tab에서 일반 창으로 표시되지 않습니다.

## 실행

Windows에서 Node.js, Rust MSVC 도구 체인, Microsoft C++ 빌드 도구와 Windows SDK, WebView2가 필요합니다. [Tauri 개발 환경 안내](https://v2.tauri.app/start/prerequisites/)를 참고하세요.

```powershell
npm ci
npm run tauri dev
```

개발 서버 없이 실행할 데스크톱 파일을 빌드하려면 다음을 실행합니다.

```powershell
npm run tauri build -- --no-bundle
```

실행 파일: `src-tauri/target/release/cornerbits.exe`. 현재 설치 프로그램과 공개 배포는 구성하지 않았습니다.

브라우저에서 화면과 저장 흐름만 확인하려면 `npm run dev` 후 `http://127.0.0.1:1420`을 엽니다. 브라우저 모드는 화면에 명시되며, 설치된 앱의 저장 파일과 완전히 별도로 관리됩니다.

## 사용

- 위쪽 물고기·화분·검·상자는 `낚시`·`정원`·`검 키우기`·`관리`입니다. 그림을 누르고, 정확한 이름과 조건은 툴팁/도감에서 확인합니다.
- 낚시: 배 위 낚시꾼 장면을 눌러 던지고 찌가 움직이면 같은 장면을 눌러 잡습니다. 낚싯대1단계는18~30초 대기·5초 반응 여유이며, 강화마다 대기0.5초 단축·반응1초 증가로8단계는14.5~26.5초 대기·12초 반응 여유입니다. 빠르게 반응할수록 추가 판매가가 붙습니다. 진행 중 저장된 낚시는 강화 규칙이 바뀌어도 입질 시각이나 어종을 다시 계산하지 않습니다.
- 잡은 물고기는 보관하며 상점에서 일괄 판매합니다. 최근 잡은 서로 다른3종이 그림으로 남고, 판매 후에도 전시와 도감은 유지합니다. 물고기 그림을 누르면 해당 도감을 엽니다.36어종의 전용 그림·6지역 풍경·8단계 장비 그림으로 발견과 성장을 구별합니다. 도구 메뉴는 `상점`·`도감`·`장비`·`지역`으로 나뉘며 미끼 선택과 강화는 장비, 낚시터 선택은 지역에 있습니다. 주요 목표는1,500마리·36종·낚싯대8단계입니다.
- 기본 미끼는 무료입니다. 풀잎/반짝 미끼는5개에50/150코인으로 구매하며, 던질 때1개를 사용해 실패해도 돌려받지 않습니다. 희귀 어종 비중은 기본/풀잎/반짝 미끼가7/12/27%입니다. 낚시터6곳은 누적70/220/450/800/1,200마리와 직전 지역4종 수집을 함께 만족하면 영구 개방합니다. 각 지역25번째 성공에서는 미발견종을 우선합니다.
- 검 키우기: 큰 검을 누르면 연마해 재료20개를 얻고, 타이밍 홈에 맞추면28개입니다. 연마는10초 간격입니다. 망치는 일반 강화, 룬은 재료와 조각을 쓰는100% 안정 강화입니다. 일반 확률은 단계별80/40/20/10/5/2%이며39회 연속 실패 뒤 다음은100%입니다. 실패해도 검은 유지되고 조각을 얻습니다. 주요 목표+60, 외형10종입니다. 화면과 돋보기에서 현재 확률·보정·정확한 비용을 확인합니다.
- 정원: 빈 화분을 눌러 심고, 물뿌리개 표식이 있을 때 물을 주면 전체 성장 시간이25% 줄어듭니다. 기본60/90/120/이후180초이며 앱을 닫아도 자라고 시들지 않습니다. 돋보기에서8종씩 넘기는 씨앗 그림 도감을 고르고 화분을 확장합니다. 목표40종 직접 수확·화분12개이며 열린 씨앗은 영구 보존합니다.
- 성장/입질/연마 시간 표시만으로 저장하지 않습니다. 낚시를 던질 때 어종·입질 시각·난수, 검을 강화할 때 난수와 결과, 정원 행동을 저장합니다. 재실행해도 같은 낚시/강화 기록이 이어집니다.
- 게임·관리·접힌 막대에 큰 배경을 두지 않습니다. 작은 그림과 최소한의 상태 표시를 유지하고 자세한 수치·도구는 눌러 확인합니다. 저장 오류·저장 중·재시도·복원 경고는 숨기지 않습니다. 짧은 움직임은 모션 감소 설정을 따르고 문서가 숨으면 정지합니다. 키보드 포커스와 접근성 이름을 제공합니다.
- 위쪽 드래그 영역을 잡고 모니터 사이로 옮깁니다. 정상 종료 시 위치를 기억하며 재실행/접기·펼치기 때 화면 안으로 복구합니다. 기본280×380, 접힌 막대280×36 논리픽셀입니다.
- `Win+D` 또는 트레이 `위젯 찾기`로 찾고, `×`나 트레이 `종료`로 종료합니다. 종료 시 진행 중인 저장을 기다립니다.
- 관리의 위쪽 화살표 상자가 백업 내보내기, 아래쪽 화살표 상자가 백업 복원입니다. 복원 전 현재 기록을 따로 보관합니다. 저장 실패 시 추가 행동을 잠그며 `저장 다시 시도`로 복구합니다.
- 이전 광산·회로는 현재 메뉴에서 교체됐지만, 기록은 저장/백업에 보존합니다. 새 게임 진행과 이전 기록은 독립적입니다.

## 데이터

앱 식별자는 `dev.cornerbits.app`으로 고정합니다. Windows에서는 Tauri의 앱 데이터 폴더인 `%APPDATA%\dev.cornerbits.app`에 저장하며 설치·빌드 폴더와 분리됩니다.

- `state.json`: 버전7의 설정·세 게임과 이전 광산/회로 기록, 낚시의 전시 어종 최대3개.
- `window-position.json`: 창 위치.
- `snapshots/`: 날짜가 바뀐 후 첫 변경 전 상태, 복원 직전 상태, 이전 저장 형식 변환 전 원본, 필요한 경우 원본 복구 파일.

일일 스냅샷은 UTC 날짜를 기준으로 합니다. 기존 백업의 자동 삭제를 하지 않습니다. 중요한 기록은 별도 위치로 수동 내보내기를 권합니다.

상태는 버전7, 백업 봉투는 버전1입니다. v1~v6 원본을 먼저 보존한 뒤 v7로 이전하며, 원본 보존 실패 시 변환하지 않습니다. v6의 모든 기존 필드와 다른 게임·설정·저장번호·시각을 그대로 유지하고 전시 어종만 추가합니다. 과거 기록에는 어획 순서가 없으므로 기존 발견 어종 인덱스 역순으로 최대3종을 골라 전시하며, 이를 최근 어획 순서로 간주하지 않습니다.

v1~v4에서는 기존 게임·설정·저장번호·시각을 유지하고 낚시와 검만 새로 시작합니다. v5의 코인·도감·진행 중 입질의 어종/시각·난수와 다른 게임 기록도 그대로 보존합니다. 이전 낚시는 잡는 즉시 코인을 지급했으므로 이미 잡은 물고기를 판매 재고로 다시 지급하지 않습니다. v5에서 오는 새 물고기 재고·판매 보너스·유료 미끼 재고는0으로 시작하고, 기존 누적 마릿수와 현재 위치로 열린 지역을 보존합니다. v5/v6의 발견 기록에서 전시 어종을 복원하며 이전 백업 복원 화면에서 변경을 안내합니다. v7 저장은 이전 실행 파일에서 읽을 수 없습니다.

잘못된 형식·게임 값, 지원하지 않는 버전, 2 MiB를 넘는 백업은 현재 기록을 바꾸지 않고 거부합니다. 파일은 UTF-8 JSON입니다. 저장은 같은 폴더의 임시 파일을 디스크에 쓴 후 원자적으로 교체합니다. 상태 저장과 복원은 하나씩 실행합니다. 변환 전 `.json`은 원본 보존용이며, 앱에서 가져올 때는 내보낸 `.cornerbits` 백업을 사용합니다.

## 분량 기준

각 게임 하루10~15분·주요 목표 약60일을 목표로 하며 일일 제한은 없습니다. `npm run balance`로 실제 reducer 모델을 재현합니다. 하루12.5분 기준 낚시58일·정원58일·검100시드 중앙60.46일입니다. 낚시는 하루10/15분이면73/48일로 계산됩니다. 시간에는 입질·성장·연마 대기를 포함하며 순수 능동 조작10~15분을 뜻하지 않습니다. 선택·반응·접속 패턴·강화 운에 따라 달라지고 실제60일 체험을 검증한 수치는 아닙니다. 자세한 가정은 [진행량 모델](docs/balance.md)에 있습니다.

## 검증

```powershell
npm run typecheck
npm test
npx playwright install chromium
npm run test:e2e
npm run build
npm run check:native
```

단위 테스트는 게임 규칙·장비별 시간 효과·엄격한 방문 예산·이전 회로300 퍼즐·수치/시간 경계, 상태 검증, 백업 왕복, 저장 순서·실패 복구와 종료 대기를 확인합니다. 브라우저 테스트는 세 게임 실제 행동 후 재실행/백업 왕복, 전시 어종의 판매 후 보존, 지역/장비 그림, 오프라인 수확, 이전 저장 변환 원본 보존, 손상 거부, 저장 실패 잠금, 모션 감소, 투명 화면을 확인합니다. Rust 테스트는 실제 임시 폴더 저장·v1~v6→v7 변환·스냅샷·복원·원자 교체와 TS 공통 fixture를 확인합니다. 낚시 판매·미끼 구매/소모·재고·활성 입질·전시 어종도 저장/백업 왕복 대상입니다.

Windows 위젯의 창 순서·Win+D·트레이·네이티브 파일 선택 대화상자는 실제 데스크톱 검증이 별도로 필요합니다.

현재 PC에서 최소 개발 도구 구성으로 빌드할 때는 먼저 `. .\.tools\native-env.ps1`을 실행합니다. `.tools/`는 이 PC에만 준비한 폴더로 Git에 포함하지 않습니다.

정식 실행 파일은 `src-tauri/target/release/cornerbits.exe`입니다. 버전별 자동 테스트 결과와 실제 Windows 수동 확인 범위는 [검증 기록](docs/verification.md)에 있습니다.
