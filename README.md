# CornerBits

화면 구석에 두는 작은 Windows 앱입니다. v0.0.1은 게임을 추가하기 전의 공통 기반으로, 창 제어와 자동 저장·백업 내보내기·복원을 제공합니다.

## 실행

Windows에서 Node.js, Rust MSVC 도구 체인, Microsoft C++ 빌드 도구와 Windows SDK, WebView2가 필요합니다. [Tauri 개발 환경 안내](https://v2.tauri.app/start/prerequisites/)를 참고하세요.

```powershell
npm ci
npm run tauri dev
```

개발 서버 없이 실행할 데스크톱 파일을 빌드하려면 다음을 실행합니다.

```powershell
npm run tauri build -- --no-bundle
```

실행 파일: `src-tauri/target/release/cornerbits.exe`. 현재 설치 프로그램과 공개 배포는 구성하지 않았습니다.

브라우저에서 화면과 저장 흐름만 확인하려면 `npm run dev` 후 `http://127.0.0.1:1420`을 엽니다. 브라우저 모드는 화면에 명시되며, 설치된 앱의 저장 파일과 완전히 별도로 관리됩니다.

## 사용

- 제목을 드래그해 창을 이동합니다. 창 위치는 정상 종료 시 기억하며 연결된 모니터 안으로 복구합니다.
- `축소`를 누르면 280×36 막대가 되고, `펼침`으로 돌아옵니다. 기본 창은 280×380 논리픽셀입니다.
- `항상 위에 표시`를 변경하면 설정이 자동 저장됩니다. 기본값은 꺼짐입니다.
- `백업 내보내기`에서 `.cornerbits` 파일의 저장 위치를 선택합니다.
- `백업에서 복원`으로 파일을 선택하고 내용을 확인한 뒤 `이 백업으로 복원`을 누릅니다. 복원 전 현재 기록은 별도 보관합니다.
- 저장 실패 시 오류와 `저장 다시 시도`가 표시됩니다. 정상 종료는 진행 중인 작업과 저장 완료를 기다립니다. 전원 차단·프로세스 강제 종료 전 아직 쓰기를 완료하지 못한 변경까지 보장하지는 않습니다.

## 데이터

앱 식별자는 `dev.cornerbits.app`으로 고정합니다. Windows에서는 Tauri의 앱 데이터 폴더인 `%APPDATA%\dev.cornerbits.app`에 저장하며 설치·빌드 폴더와 분리됩니다.

- `state.json`: 버전 번호가 포함된 설정. 현재 단계에는 게임 데이터가 없습니다.
- `window-position.json`: 창 위치.
- `snapshots/`: 날짜가 바뀐 후 첫 변경 전 상태, 복원 직전 상태, 필요한 경우 원본 복구 파일.

일일 스냅샷은 UTC 날짜를 기준으로 합니다. 1단계에서는 기존 백업의 자동 삭제를 하지 않습니다. 중요한 기록은 별도 위치로 수동 내보내기를 권합니다.

현재 상태 형식과 백업 형식은 각각 버전 1입니다. 잘못된 형식, 지원하지 않는 버전, 2 MiB를 넘는 백업은 현재 기록을 바꾸지 않고 거부합니다. 파일은 UTF-8 JSON입니다. 저장은 같은 폴더의 임시 파일을 디스크에 쓴 후 원자적으로 교체합니다. 상태 저장과 복원은 하나씩 실행합니다.

## 검증

```powershell
npm run typecheck
npm test
npx playwright install chromium
npm run test:e2e
npm run build
npm run check:native
```

단위 테스트는 상태 검증, 백업 왕복, 저장 순서·실패 복구와 종료 대기를 확인합니다. 브라우저 테스트는 재실행 후 자동 저장, 내보내기·복원·취소, 손상 파일 거부와 막대 모드를 확인합니다. Rust 테스트는 실제 임시 폴더에서 저장·스냅샷·복원·파일 교체 실패를 확인합니다.

Windows 창·트레이·네이티브 파일 선택 대화상자는 데스크톱 실행 검증이 별도로 필요합니다.

현재 작업 환경에서는 Windows 애플리케이션 제어 정책(오류 4551)이 Cargo 빌드 스크립트 실행을 차단해 네이티브 빌드·실행을 확인하지 못했습니다. 자세한 결과는 [검증 기록](docs/verification.md)에 있습니다.
