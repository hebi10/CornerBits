# CornerBits · 해안 생활

v0.8.0은 낚시·채집으로 모은 자원을 집 꾸미기와 확장에 사용하는 작은 해안 생활입니다. 집·나무·부두·작은 배가 하나의 컬러 픽셀 풍경에 놓이고, 280×380 Windows 위젯의 바깥은 투명합니다.

- 부두를 누르면 인물이 걸어가 낚시하고 집 앞에 물고기를 겁니다. 물고기 걸이나 집 메뉴에서 한 마리당 15조개코인에 판매합니다.
- 해변을 누르면 나무를 주워옵니다. 집을 2·3단계로 확장하면 낚시·채집에서 한 번에 얻는 양이 각각 2·3개로 늘어납니다.
- 집을 누르면 꽃화분·등불·벤치를 제작하거나 집을 확장합니다. 장식과 성장한 집은 같은 풍경에 남습니다.
- 물결·굴뚝 연기·걷기와 행동이 움직입니다. 정지·숨김·접기·집/기록 메뉴를 여는 동안 진행이 멈추며, 모션 감소를 지원합니다.
- 행동 시작·완료·판매와 중간 체크포인트를 자동 저장합니다. 진행 중 종료해도 저장된 지점부터 이어지고, 닫아 둔 시간의 반복 보상은 생기지 않습니다.

현재 범위는 집 3단계와 장식 3종의 **첫 성장 구간**입니다. 새 해안 생활에 60일 분량을 보장하는 장기 밸런스는 아직 적용하지 않았습니다.

## 자원과 성장

| 대상 | 필요한 집 단계 | 나무 | 조개코인 |
|---|---:|---:|---:|
| 꽃화분 | 1 | 3 | 20 |
| 등불 | 2 | 6 | 45 |
| 벤치 | 3 | 12 | 90 |
| 집 1 → 2 확장 | 1 | 12 | 75 |
| 집 2 → 3 확장 | 2 | 25 | 150 |

제작·확장 비용은 시작할 때 차감합니다. 작업 도중 저장·복원해도 비용을 다시 내지 않습니다. 장식은 각 한 번 제작하며, 해금된 장식과 집 확장 중 어디에 재료를 쓸지 선택할 수 있습니다.

## 실행과 개발

기존 Node.js/Rust MSVC/Microsoft C++/Windows SDK/WebView2 환경을 사용합니다.

```powershell
npm ci
npm run tauri dev
```

브라우저: `npm run dev` 후 `http://127.0.0.1:1420/coast.html`.

```powershell
npm run tauri build -- --no-bundle
```

실행파일은 `src-tauri/target/release/cornerbits.exe`이며 기본 화면은 coast.html입니다. 이 PC의 최소 도구 환경에서는 먼저 `. .\.tools\native-env.ps1`을 실행합니다.

## 위젯 조작

위쪽 여백을 끌어 이동하고, 정지/재생·기록·접기·닫기를 사용합니다. 배경화면 위·다른 앱 뒤에 머물며 작업 표시줄/Alt+Tab에 일반 창으로 나타나지 않습니다. 트레이의 위젯 찾기/종료는 유지합니다. 접으면 280×36 막대가 되며, 창 크기만 바꾸고 기존 compact 설정은 변경하지 않습니다.

## 자동 저장과 백업

Windows 저장 위치는 `%APPDATA%\dev.cornerbits.app\state.json`이며, 보호용 스냅샷은 같은 폴더의 `snapshots`에 보관합니다. 매 애니메이션 프레임 대신 행동 시작·완료, 판매, 정지·숨김·접기, 메뉴 열기, 백업과 종료 때 필요한 진행을 저장합니다. 저장 실패 시 진행을 멈추고 같은 내용을 재시도하므로 보상이나 비용이 중복 계산되지 않습니다. 정상 종료는 저장이 끝날 때까지 기다립니다.

위쪽 **기록**에서 `.cornerbits` 백업을 내보내거나 가져옵니다. 가져온 백업의 내용을 확인하고 **이 백업으로 복원**을 누르면 진행 중인 작업·재료·집·장식까지 돌아갑니다. 복원 직전의 기록도 별도 스냅샷으로 보관합니다. 백업 파일은 UTF-8 JSON, 최대 2 MiB입니다.

schema8은 기존 다섯 게임과 설정을 보존하면서 `games.coast`를 추가합니다. schema1~7 기록은 원본을 먼저 보관한 뒤 새 해안을 처음 상태로 추가합니다. 이전 버전 백업을 복원하면 기존 게임도 백업 시점으로 돌아가며, 그 백업에 없는 해안 생활은 처음부터 시작합니다. v0.7.0 화면 체험판의 임시 행동은 저장된 적이 없어 이어지지 않습니다. 기존 `index.html`과 게임 코드는 회귀 검증용으로 남아 있습니다.

브라우저의 저장·백업은 `localStorage`를 사용하며 설치된 Windows 앱 파일과 분리됩니다. 과거 세 게임의 분량 결과는 [검증 기록](docs/verification.md)과 [이전 진행량 모델](docs/balance.md)에 남아 있습니다.

## 검증

```powershell
npm run typecheck
npm test
npm run test:e2e
npm run build
```

기존 테스트는 `index.html`의 보존된 앱을 확인합니다. 해안 생활의 모델·저장 세션·브라우저 테스트는 자원 사용, 성장, 진행 중 재개, 백업 복원, 저장 실패 재시도와 실제 크기·모션 감소를 다룹니다. 자산 프롬프트와 출처는 `public/art/coast-prompts.json`, 성장 그림은 `public/art/coast-growth-prompts.json`, 현재 기획은 [해안 성장 명세](docs/superpowers/specs/2026-10-28-coastal-growth.md)에 있습니다. 공개 배포나 설치 프로그램은 구성하지 않았습니다.
