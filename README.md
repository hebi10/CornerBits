# CornerBits

화면 구석에 두는 작은 Windows 게임 앱입니다. v0.1.0은 미니 광산·작은 정원과 창 제어, 게임 진행도 자동 저장·백업 내보내기·복원을 제공합니다.

## 실행

Windows에서 Node.js, Rust MSVC 도구 체인, Microsoft C++ 빌드 도구와 Windows SDK, WebView2가 필요합니다. [Tauri 개발 환경 안내](https://v2.tauri.app/start/prerequisites/)를 참고하세요.

```powershell
npm ci
npm run tauri dev
```

개발 서버 없이 실행할 데스크톱 파일을 빌드하려면 다음을 실행합니다.

```powershell
npm run tauri build -- --no-bundle
```

실행 파일: `src-tauri/target/release/cornerbits.exe`. 현재 설치 프로그램과 공개 배포는 구성하지 않았습니다.

브라우저에서 화면과 저장 흐름만 확인하려면 `npm run dev` 후 `http://127.0.0.1:1420`을 엽니다. 브라우저 모드는 화면에 명시되며, 설치된 앱의 저장 파일과 완전히 별도로 관리됩니다.

## 사용

- `광산`: 5×5 칸을 눌러 채굴합니다. 모두 캐면 다음 층으로 내려가고, 광물을 판매해 곡괭이를 강화합니다. 목표는 1,000층·광물 30종·곡괭이 10단계입니다.
- `정원`: 씨앗을 고르고 빈 화분을 누릅니다. 한 번 물을 주면 성장 시간이 25% 줄어듭니다. 다 자라면 눌러 수확합니다. 직전 품종 5회 수확으로 다음 씨앗을 열고, 수확 코인으로 화분을 3개에서 12개까지 늘립니다. 식물은 40종이며 앱을 꺼도 자라고 시들지 않습니다.
- 처음 새싹은 1분(물주기 후 45초), 다음 두 품종은 5분·30분입니다. 이후 6시간·32시간·48시간으로 길어집니다. 도감에서 성장 시간과 다음 씨앗 조건을 확인할 수 있습니다.
- 두 게임의 재화·도감은 독립적입니다. 광산은 누르던 칸의 내구도, 정원은 품종·심은 시각·물주기까지 주요 행동마다 저장합니다. 단순 성장 시간 표시는 디스크를 계속 쓰지 않습니다.
- 제목을 드래그해 창을 이동합니다. 창 위치는 정상 종료 시 기억하며 연결된 모니터 안으로 복구합니다.
- `축소`를 누르면 280×36 막대가 되고, `펼침`으로 돌아옵니다. 기본 창은 280×380 논리픽셀입니다.
- `관리`에서 `항상 위에 표시`를 변경하면 설정이 자동 저장됩니다. 기본값은 꺼짐입니다.
- `관리`의 `백업 내보내기`에서 `.cornerbits` 파일의 저장 위치를 선택합니다. 게임 두 개의 진행도·도감·재화·설정을 함께 보관합니다.
- `백업에서 복원`으로 파일을 선택하고 내용을 확인한 뒤 `이 백업으로 복원`을 누릅니다. 복원 전 현재 기록은 별도 보관합니다.
- 저장 실패 시 오류와 `저장 다시 시도`가 표시됩니다. 정상 종료는 진행 중인 작업과 저장 완료를 기다립니다. 전원 차단·프로세스 강제 종료 전 아직 쓰기를 완료하지 못한 변경까지 보장하지는 않습니다.

## 데이터

앱 식별자는 `dev.cornerbits.app`으로 고정합니다. Windows에서는 Tauri의 앱 데이터 폴더인 `%APPDATA%\dev.cornerbits.app`에 저장하며 설치·빌드 폴더와 분리됩니다.

- `state.json`: 버전 2의 설정과 두 게임 진행도.
- `window-position.json`: 창 위치.
- `snapshots/`: 날짜가 바뀐 후 첫 변경 전 상태, 복원 직전 상태, 이전 저장 형식 변환 전 원본, 필요한 경우 원본 복구 파일.

일일 스냅샷은 UTC 날짜를 기준으로 합니다. 기존 백업의 자동 삭제를 하지 않습니다. 중요한 기록은 별도 위치로 수동 내보내기를 권합니다.

상태 형식은 버전 2, 백업 봉투 형식은 버전 1입니다. 1단계 설정은 원본을 먼저 보존한 뒤 게임 초기 상태를 추가합니다. 1단계 백업도 복원할 수 있으나 게임 기록이 없는 백업이므로 게임 진행도는 초기 상태가 됩니다. 복원 확인 화면에 이를 안내합니다. 새 버전 저장 파일은 이전 실행 파일에서 읽을 수 없습니다.

잘못된 형식·게임 값, 지원하지 않는 버전, 2 MiB를 넘는 백업은 현재 기록을 바꾸지 않고 거부합니다. 파일은 UTF-8 JSON입니다. 저장은 같은 폴더의 임시 파일을 디스크에 쓴 후 원자적으로 교체합니다. 상태 저장과 복원은 하나씩 실행합니다. 변환 전 `.json`은 원본 보존용이며, 앱에서 가져올 때는 내보낸 `.cornerbits` 백업을 사용합니다.

## 분량 기준

게임마다 하루 10~15분, 주요 목표 약 60일이 초기 설계 기준입니다. 광산 1,000층 시뮬레이션은 채굴 입력 49,975회이며 실제 속도는 클릭 간격에 따라 달라집니다. 정원은 매일 한 번 10분 동안 수확·확장·최신 씨앗 심기·물주기를 반복하는 시뮬레이션에서 59일째 40종을 수확했습니다. 하루 두 번 5분씩 관리하면 46일째였습니다. 실제 플레이로 검증된 소요 시간은 아니며, 정원에 반복 조작을 강제하지 않습니다.

## 검증

```powershell
npm run typecheck
npm test
npx playwright install chromium
npm run test:e2e
npm run build
npm run check:native
```

단위 테스트는 게임 규칙·경제·시간 경계, 상태 검증, 백업 왕복, 저장 순서·실패 복구와 종료 대기를 확인합니다. 브라우저 테스트는 실제 게임 행동 후 재실행, 두 게임 백업·복원, 오프라인 수확, v1 변환과 원본 보존, 손상 파일 거부와 막대 모드를 확인합니다. Rust 테스트는 실제 임시 폴더에서 저장·변환 스냅샷·복원·파일 교체 실패와 프런트엔드와 공유하는 백업 fixture를 확인합니다.

Windows 창·트레이·네이티브 파일 선택 대화상자는 데스크톱 실행 검증이 별도로 필요합니다.

현재 PC에서 최소 개발 도구 구성으로 빌드할 때는 먼저 `. .\.tools\native-env.ps1`을 실행합니다. `.tools/`는 이 PC에만 준비한 폴더로 Git에 포함하지 않습니다.

정식 실행 파일은 `src-tauri/target/release/cornerbits.exe`입니다. 버전별 자동 테스트 결과와 실제 Windows 수동 확인 범위는 [검증 기록](docs/verification.md)에 있습니다.
