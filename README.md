# CornerBits · 해안 생활

v0.9.1은 한 번 맡긴 낚시·채집을 계속하며 모은 자원을 집 꾸미기와 확장에 사용하는 작은 해안 생활입니다. 작업 옆에서 이번 작업의 누적 시간과 획득량을 확인할 수 있습니다. 집·나무·부두·작은 배가 하나의 컬러 픽셀 풍경에 놓이고, 280×380 Windows 위젯의 바깥은 투명합니다.

[Windows 다운로드 · 최신 Release](https://github.com/hebi10/CornerBits/releases/latest) · [자동 빌드](https://github.com/hebi10/CornerBits/actions/workflows/windows.yml)

일반 사용자는 Release의 `x64-setup.exe`로 설치합니다. 설치 없이 사용하려면 `windows-x64.zip`을 풀고 `cornerbits.exe`를 실행합니다. Windows 10/11 x64와 WebView2 Runtime이 필요하며 설치 파일은 누락된 WebView2를 인터넷으로 준비합니다. [배포와 빌드 안내](docs/releasing.md)

- 부두나 해변을 한 번 누르면 낚시나 채집을 계속합니다. **기록**에서 고른 10분 또는 15분마다 한 회차를 정산하며 기본값은 10분입니다.
- 집 1단계에서 10분마다 물고기나 나무 2개, 15분마다 3개를 얻습니다. 집 2·3단계는 이 양의 2·3배를 얻습니다. 물고기는 작업 중에도 물고기 걸이나 집 메뉴에서 한 마리당 15조개코인에 판매합니다.
- 집을 누르면 꽃화분·등불·벤치를 제작하거나 집을 확장합니다. 장식과 성장한 집은 같은 풍경에 남습니다.
- 다른 앱 뒤·문서 숨김·접힘·집/기록 메뉴에서도 작업은 이어집니다. 숨김·접힘·메뉴에서는 장면 모션이 쉬며, 모션 감소를 지원합니다. 명시적인 정지, 저장 실패, 백업 복원 미리보기에서는 작업 시간이 멈춥니다.
- 작업 옆에는 **채집 12:34 · 나무 +2**처럼 이번 작업의 누적 시간과 실제로 정산된 획득량을 상시 표시합니다. 판매해도 이번 작업의 획득량은 유지됩니다. 지연된 타이머는 지난 회차를 한 번에 정산하며, 최근 정산은 기록에서 확인합니다. 회차마다 별도 장면 알림을 띄우거나 Windows 알림·소리를 사용하지 않습니다.
- 작업 시작·회차 보상·중단·판매와 60초 체크포인트를 자동 저장합니다. 진행 중 종료해도 저장된 지점부터 이어지고, 앱을 닫아 둔 시간은 계산하지 않습니다.

현재 범위는 집 3단계와 장식 3종의 **첫 성장 구간**입니다. 새 해안 생활에 60일 분량을 보장하는 장기 밸런스는 아직 적용하지 않았습니다.

## 자원과 성장

| 대상 | 필요한 집 단계 | 나무 | 조개코인 |
|---|---:|---:|---:|
| 꽃화분 | 1 | 3 | 20 |
| 등불 | 2 | 6 | 45 |
| 벤치 | 3 | 12 | 90 |
| 집 1 → 2 확장 | 1 | 12 | 75 |
| 집 2 → 3 확장 | 2 | 25 | 150 |

**작업 중단**은 이미 모은 재료를 남기고 현재 회차와 이번 작업 집계를 끝냅니다. 새 작업의 시간·획득량은 0부터 시작합니다. 제작·집 확장·정산 간격 변경 전에는 진행 중인 작업을 중단합니다. 제작·확장 비용은 시작할 때 차감하며, 도중에 저장·복원해도 다시 내지 않습니다. 장식은 각 한 번 제작하며, 해금된 장식과 집 확장 중 어디에 재료를 쓸지 선택할 수 있습니다. 다음 회차 보상을 보관할 수 있는 상한에 도달하면 작업을 마칩니다.

## 실행과 개발

기존 Node.js/Rust MSVC/Microsoft C++/Windows SDK/WebView2 환경을 사용합니다.

```powershell
npm ci
npm run tauri dev
```

브라우저: `npm run dev` 후 `http://127.0.0.1:1420/coast.html`.

```powershell
npm run tauri build -- --no-bundle
```

실행파일은 `src-tauri/target/release/cornerbits.exe`이며 기본 화면은 coast.html입니다. 이 PC의 최소 도구 환경에서는 먼저 `. .\.tools\native-env.ps1`을 실행합니다.

## 위젯 조작

위쪽 여백을 끌어 이동하고, 정지/재생·기록·접기·닫기를 사용합니다. 배경화면 위·다른 앱 뒤에 머물며 작업 표시줄/Alt+Tab에 일반 창으로 나타나지 않습니다. 트레이의 위젯 찾기/종료는 유지합니다. 접으면 280×36 막대가 되며, 창 크기만 바꾸고 기존 compact 설정은 변경하지 않습니다.

## 자동 저장과 백업

Windows 저장 위치는 `%APPDATA%\dev.cornerbits.app\state.json`이며, 보호용 스냅샷은 같은 폴더의 `snapshots`에 보관합니다. 표시 시간은 메모리에서 진행하며 작업 시작·회차 보상·중단·간격 변경·판매·제작, 60초 체크포인트, 정지·숨김·접기·메뉴 열기·백업·종료 때 필요한 진행을 저장합니다. 보상은 저장 성공 후 표시합니다. 저장 실패 시 진행을 멈추고 같은 스냅샷을 재시도하므로 보상이나 비용이 중복 계산되지 않습니다. 정상 종료는 저장이 끝날 때까지 기다립니다.

위쪽 **기록**에서 `.cornerbits` 백업을 내보내거나 가져옵니다. 가져온 백업의 내용을 확인하고 **이 백업으로 복원**을 누르면 진행 중인 작업·이번 작업의 시간과 획득량·재료·집·장식까지 돌아갑니다. 복원 직전의 기록도 별도 스냅샷으로 보관합니다. 백업 파일은 UTF-8 JSON, 최대 2 MiB입니다.

schema10은 기존 다섯 게임·설정과 해안 기록을 보존하면서 `games.coast`에 이번 작업의 총시간 `workTimeMs`와 정산 획득량 `workAmount`를 추가합니다. 정산 간격 `workInterval`과 최근 정산 `lastReport`도 유지합니다. schema9의 정확한 이전 형식을 검증하고 원본을 먼저 보관한 뒤, 낚시·채집 중이면 저장된 회차 경과 시간부터 작업 시간을 집계합니다. 이전 형식에 없는 작업별 획득량은 0부터 시작하며, 과거 정산이나 보유 재료로 추정하지 않습니다. 작업 중이 아니면 두 집계값은 0입니다.

schema8 기록은 이전 규칙으로 검증하고 원본을 먼저 보관한 뒤 10분 간격·최근 정산 없음과 같은 작업 집계 기준으로 이관합니다. 진행 중인 낚시·채집의 경과 시간과 재료·집·장식은 보존해 긴 첫 회차로 이어갑니다. 단, 다음 회차 보상을 보관할 수 없다면 작업을 중단하고 회차 시간과 작업 집계를 0으로 정리하며, 보유 자원과 집·장식은 남깁니다.

schema1~7 기록도 원본을 먼저 보관한 뒤 새 해안을 처음 상태로 추가합니다. 이전 버전 백업을 복원하면 기존 게임도 백업 시점으로 돌아가며, 해안 기록이 없는 백업에서는 해안 생활을 처음부터 시작합니다. v0.7.0 화면 체험판의 임시 행동은 저장된 적이 없어 이어지지 않습니다. 기존 `index.html`과 게임 코드는 회귀 검증용으로 남아 있습니다.

브라우저의 저장·백업은 `localStorage`를 사용하며 설치된 Windows 앱 파일과 분리됩니다. 과거 세 게임의 분량 결과는 [검증 기록](docs/verification.md)과 [이전 진행량 모델](docs/balance.md)에 남아 있습니다.

```powershell
npm run typecheck
npm test
npm run test:e2e
npm run build
```

기존 테스트는 `index.html`의 보존된 앱을 확인합니다. 해안 생활의 모델·저장 세션·브라우저 테스트는 작업 시간·획득량 집계, 10분·15분 회차와 지연 정산, 중단·판매·간격 변경, 숨김·접힘·메뉴에서의 진행, 성장, 진행 중 재개, 백업 복원, 구버전 이관, 저장 실패 재시도와 실제 크기·모션 감소를 다룹니다. 자산 프롬프트와 출처는 `public/art/coast-prompts.json`, 성장 그림은 `public/art/coast-growth-prompts.json`, 현재 기획은 [연속 작업 명세](docs/superpowers/specs/2026-10-28-coastal-idle.md)와 [해안 성장 명세](docs/superpowers/specs/2026-10-28-coastal-growth.md)에 있습니다. Windows 설치 파일과 압축 실행본은 GitHub Actions에서 생성하고 버전 태그를 통해 Releases에 공개합니다.
