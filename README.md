# CornerBits

바탕화면 한쪽에 놓는 작은 Windows 장식 위젯입니다. v0.3.0은 세 게임의 진행량을 조정하고, 정원 도구를 작은 그림 도감으로 제공합니다. 표정 있는 흑백 돌·화분·전구를 눌러 조작하며 진행도를 자동 저장하고 통합 백업·복원합니다. 일반 프로그램보다 뒤에 머물며 작업 표시줄과 Alt+Tab 목록에 일반 창으로 표시되지 않습니다.

## 실행

Windows에서 Node.js, Rust MSVC 도구 체인, Microsoft C++ 빌드 도구와 Windows SDK, WebView2가 필요합니다. [Tauri 개발 환경 안내](https://v2.tauri.app/start/prerequisites/)를 참고하세요.

```powershell
npm ci
npm run tauri dev
```

개발 서버 없이 실행할 데스크톱 파일을 빌드하려면 다음을 실행합니다.

```powershell
npm run tauri build -- --no-bundle
```

실행 파일: `src-tauri/target/release/cornerbits.exe`. 현재 설치 프로그램과 공개 배포는 구성하지 않았습니다.

브라우저에서 화면과 저장 흐름만 확인하려면 `npm run dev` 후 `http://127.0.0.1:1420`을 엽니다. 브라우저 모드는 화면에 명시되며, 설치된 앱의 저장 파일과 완전히 별도로 관리됩니다.

## 사용

- 위쪽 돌·화분·전구·상자 그림은 각각 `광산`·`정원`·`회로`·`관리`입니다. 마우스를 올리면 이름과 조작 설명을 볼 수 있고, 키보드 포커스와 접근성 이름도 제공합니다.
- `광산`: 5×5 돌 그림을 눌러 채굴합니다. 모두 캐면 아래 사다리로 다음 층에 내려갑니다. 주머니는 광물 판매, 곡괭이는 강화, 돋보기는 기록입니다. 목표는 1,000층·광물 30종·곡괭이 10단계입니다.
- `정원`: 빈 화분을 누르면 선택한 씨앗을 심습니다. 물뿌리개 표식이 있는 화분을 누르면 성장 시간이 25% 줄고, 다 자란 화분은 천천히 움직이며 누르면 수확합니다. 돋보기를 열면 화분 대신 8종씩 넘기는 그림 도감이 나옵니다. 열린 씨앗 그림을 눌러 선택하고, 화분 추가 그림으로 확장합니다. 직전 품종의 필요 수확량은 초반 5·12·20회, 이후 50·90·120회로 늘며 도감에 다음 조건을 표시합니다. 화분 3→12개, 식물 40종이며 앱을 꺼도 자라고 시들지 않습니다.
- `회로`: 전구를 누를 때마다 연결선이 시계 방향으로 90도 돌아갑니다. 배터리에서 모든 전구까지 전기가 닿고 선 끝도 모두 맞으면 완료입니다. 1~150번은 4×4, 151~300번은 5×5, 총 300개입니다. 플러그는 현재 퍼즐 다시 시작, 사다리는 완료 후 다음 퍼즐, 돋보기는 안내·기록·완료 퍼즐 재도전입니다. 회전 중 상태·최소 완료 회전수·누적 완료를 저장합니다. 기록은 개인 기록이며 수학적 최단해 보장이 아닙니다.
- 성장 시간은 새싹 1분, 다음 두 품종 1분30초·2분, 이후 3분입니다. 물을 주면 각각 45초·67.5초·90초·135초가 됩니다. 이미 열린 씨앗은 영구 보존하며 이전 버전 저장을 옮겨도 다시 잠기지 않습니다.
- 세 게임의 기록은 독립적입니다. 광산의 칸 내구도, 정원의 품종·심은 시각·물주기, 회로의 각 칸 회전과 횟수까지 주요 행동마다 저장합니다. 단순 성장 시간 표시는 디스크를 계속 쓰지 않습니다.
- 광산은 돌의 균열·채굴 터, 정원은 씨앗·새싹·잎·성숙 식물 그림으로 진행 상태를 보여줍니다. 그림에 마우스를 두거나 도감을 열면 자세한 이름과 수치를 확인할 수 있습니다. 30종 광물은 4개 그림군, 40종 식물은 12개 성숙 그림군을 공유합니다.
- 게임·관리 모두 큰 배경과 테두리 없이 그림이 먼저 보입니다. 저장 상태·보관함 설명·하단 문구도 배경 없이 표시합니다. 상시 글자 버튼·점수는 줄이고 그림 도구와 툴팁으로 대체했습니다. 펼친 안내·도감·오류·복원 확인에는 읽기 쉬운 배경을 사용합니다. 마지막 저장 시각은 저장 표시 위에 마우스를 두면 확인합니다.
- 랜턴과 식물이 천천히 움직이고, 채굴·물주기·수확에 짧은 효과가 나타납니다. 시스템의 모션 감소 설정을 따르며, 축소하거나 다른 게임으로 이동하면 해당 효과와 타이머가 정리됩니다. 문서가 숨김 상태가 되면 움직임과 정원 시계 갱신을 멈춥니다.
- 위쪽 CornerBits 제목을 드래그해 위젯을 이동합니다. 이동 중에는 모니터 경계에 위치를 고정하지 않습니다. 위치는 정상 종료 시 기억하며, 재실행하거나 크기를 바꿀 때 연결된 모니터 안으로 복구합니다.
- `축소`를 누르면 280×36 막대가 되고, `펼침`으로 돌아옵니다. 기본 창은 280×380 논리픽셀입니다.
- `Win+D`로 바탕화면을 보거나 트레이 아이콘 메뉴의 `위젯 찾기`를 사용합니다. 트레이에서 찾은 위젯은 잠시 앞으로 표시되고, 다른 앱으로 이동하면 다시 뒤로 돌아갑니다. 종료는 위젯의 `×` 또는 트레이의 `종료`를 사용합니다.
- 이전 버전의 `항상 위에 표시` 값은 백업 호환을 위해 보존하지만, 바탕화면 위젯 배치에는 적용하지 않습니다.
- `관리`의 위쪽 화살표 상자가 `백업 내보내기`입니다. `.cornerbits` 파일의 저장 위치를 선택해 세 게임의 진행도·도감·재화·설정을 함께 보관합니다.
- 아래쪽 화살표 상자의 `백업에서 복원`으로 파일을 선택하고 내용을 확인한 뒤 `이 백업으로 복원`을 누릅니다. 복원 전 현재 기록은 별도 보관합니다.
- 저장 실패 시 오류와 `저장 다시 시도`가 표시됩니다. 정상 종료는 진행 중인 작업과 저장 완료를 기다립니다. 전원 차단·프로세스 강제 종료 전 아직 쓰기를 완료하지 못한 변경까지 보장하지는 않습니다.

## 데이터

앱 식별자는 `dev.cornerbits.app`으로 고정합니다. Windows에서는 Tauri의 앱 데이터 폴더인 `%APPDATA%\dev.cornerbits.app`에 저장하며 설치·빌드 폴더와 분리됩니다.

- `state.json`: 버전 3의 설정과 세 게임 진행도.
- `window-position.json`: 창 위치.
- `snapshots/`: 날짜가 바뀐 후 첫 변경 전 상태, 복원 직전 상태, 이전 저장 형식 변환 전 원본, 필요한 경우 원본 복구 파일.

일일 스냅샷은 UTC 날짜를 기준으로 합니다. 기존 백업의 자동 삭제를 하지 않습니다. 중요한 기록은 별도 위치로 수동 내보내기를 권합니다.

상태 형식은 버전 3, 백업 봉투 형식은 버전 1입니다. v1 설정과 v2 광산/정원 저장은 정확한 원본을 먼저 보존한 뒤 v3로 변환합니다. v2의 광산/정원 기록은 유지하고 빈 회로만 추가합니다. 원본 보존이 실패하면 변환하지 않습니다. 이전 백업도 복원 가능하며 v1은 세 게임 초기화, v2는 회로 초기화를 복원 화면에서 안내합니다. v3 저장은 이전 실행 파일에서 읽을 수 없습니다.

잘못된 형식·게임 값, 지원하지 않는 버전, 2 MiB를 넘는 백업은 현재 기록을 바꾸지 않고 거부합니다. 파일은 UTF-8 JSON입니다. 저장은 같은 폴더의 임시 파일을 디스크에 쓴 후 원자적으로 교체합니다. 상태 저장과 복원은 하나씩 실행합니다. 변환 전 `.json`은 원본 보존용이며, 앱에서 가져올 때는 내보낸 `.cornerbits` 백업을 사용합니다.

## 분량 기준

게임마다 하루 10~15분, 주요 목표 약 60일을 목표로 분량을 조정했습니다. 일일 제한은 없습니다. `npm run balance`로 실제 게임 규칙을 사용한 모델을 재현할 수 있습니다. 하루 12.5분 기준 광산 약59일·정원58일·회로 약58일이며, 10분이면 약67~74일, 15분이면 약48~49일입니다. 상세 가정과 수치는 [진행량 모델](docs/balance.md)에 있습니다.

광산은 강화 비용을 단계²×500코인, 조건을 단계×40층으로 조정했습니다. 정원 모델의 접속 시간에는 성장 대기가 포함되며, 하루 평균 실제 입력은 약3~4분입니다. 회로는 기존 300개와 진행 중 퍼즐을 유지하고 작은 회로는 하루6~7개, 큰 회로는4개 정도를 안내합니다. 사고 시간은 가정이며 실제 사람의 60일 플레이를 검증한 수치는 아닙니다.

## 검증

```powershell
npm run typecheck
npm test
npx playwright install chromium
npm run test:e2e
npm run build
npm run check:native
```

단위 테스트는 게임 규칙·진행 모델·회로 300 퍼즐·수치/시간 경계, 상태 검증, 백업 왕복, 저장 순서·실패 복구와 종료 대기를 확인합니다. 브라우저 테스트는 세 게임 실제 행동 후 재실행/백업 왕복, 오프라인 수확, 이전 저장 변환 원본 보존, 그림 도감, 손상 거부, 저장 실패 잠금, 모션 감소, 투명 화면을 확인합니다. Rust 테스트는 실제 임시 폴더 저장·v1/v2/v3→v4 변환·스냅샷·복원·원자 교체와 TS 공통 v2/v3/v4 fixture를 확인합니다.

Windows 위젯의 창 순서·Win+D·트레이·네이티브 파일 선택 대화상자는 실제 데스크톱 검증이 별도로 필요합니다.

현재 PC에서 최소 개발 도구 구성으로 빌드할 때는 먼저 `. .\.tools\native-env.ps1`을 실행합니다. `.tools/`는 이 PC에만 준비한 폴더로 Git에 포함하지 않습니다.

정식 실행 파일은 `src-tauri/target/release/cornerbits.exe`입니다. 버전별 자동 테스트 결과와 실제 Windows 수동 확인 범위는 [검증 기록](docs/verification.md)에 있습니다.
